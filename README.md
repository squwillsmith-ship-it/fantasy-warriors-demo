# Fantasy Warriors — Playable Demo

A self-contained, touch-friendly, static HTML5 tower-defence prototype following the Fantasy Warriors master gameplay manifesto v0.4.0.

## Play

After GitHub Pages is enabled, open the repository website in Safari or another modern browser. No installation, backend, assets or build step required.

## GitHub Pages setup

1. Create a public GitHub repository named `fantasy-warriors-demo`.
2. Upload these files to the root of the default `main` branch.
3. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**. Choose `main`, `/(root)`, and **Save**.
4. Wait until GitHub displays the published URL. The URL typically follows `https://<username>.github.io/fantasy-warriors-demo/`, but verify the actual link in the repository's Pages settings.

## Demo controls

Purchase up to 3 hero packs, open each to recruit a hero, then press Start Stage. Heroes attack automatically. Defeat the stage boss to proceed.

The gameplay mechanics and economy are prototype values and can be changed in future versions.
